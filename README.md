<h1 align="center">GWS</h1>
<p align="center">
<a href="https://github.com/Rufis72/gws/blob/master/LICENSE"><img src="https://img.shields.io/github/license/Rufis72/gws.svg?style=for-the-badge" alt="License"></a>

GWS is a multi-purpose automation tool designed to make easily replicable macros across multiple devices, window sizes, and apps. It comes with a powerful scripting interface, and (hopefuly at some point, I haven't gotten around to this yet) a visual interface.

Note: On Wayland compositors, wayland-automation is used for input, which requires wayland-info and wtype. Depending on your compositor, there may be more required packages. For more info, see [wayland-automation's docs](https://github.com/OTAKUWeBer/Wayland-automation#Installation)
