.. _installation:

Installation
===============

To install GWS, first run:

.. code-block:: bash

    pip3 install "https://github.com/Rufis72/gws/archive/refs/heads/main.zip"

In the future GWS should be on PyPi, but currently it isn't.

Now, you're done, if you're on MacOS. If you're on Linux, you may have more
things you need to install.

System dependencies
#####################

 * wtype: This is required on Wayland to do keyboard input
 * grim: This is required on Wayland to take screenshots
 * wayland-utils: This is required on Wayland to get monitor info

Now, you're all done! You may want to check out :ref:`quick-start` for quick-ish
example for how to use GWS, or just check out the docs in general.
